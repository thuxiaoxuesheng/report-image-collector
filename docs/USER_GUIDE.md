# 网站使用文档

本文说明管理员和普通用户如何使用网站。页面名称可能随界面微调，但操作逻辑保持一致。

## 1. 登录与账号

网站不开放自行注册。管理员在“用户管理”中创建账号后，将一次性初始密码交给用户。用户首次登录必须设置至少 12 位的新密码。

请勿共用账号。每个网站用户都对应独立的平台登录目录、任务、图片和历史去重记录；视觉模型账号由管理员统一配置。账号停用后，对应任务和浏览器登录状态停止使用。

## 2. 视觉模型（可选）

管理员进入“个人设置”后，可为全站选择两种接入方式：

1. **MiniMax Token Plan**：填写管理员持有的共享 API Key。
2. **OpenAI-compatible**：填写 HTTPS Base URL、支持图片输入的模型名称和 API Key。

保存后点击“测试连接”。网站只向管理员显示掩码提示，不会把完整 API Key 返回浏览器。配置使用部署主密钥加密保存，所有普通用户共享使用但不能查看或修改。

AI 不是创建任务的前置条件。管理员不配置模型时，所有用户仍可完成采集、人工审核和导出。模型只判断图片是否像检查检验报告单，并可返回简短理由；它不做 OCR、医学分类、脱敏或医学结论判断。

## 3. 完成平台登录

1. 进入“小红书登录”。
2. 点击“打开登录浏览器”。
3. 在网页中的受限浏览器画面内自行扫码，或输入手机号和短信验证码。
4. 完成平台要求的登录确认后，等待页面显示已登录。
5. 点击“完成登录”或关闭控制画面。关闭画面不会清除登录状态。

网站不会自动读取短信、识别验证码或绕过平台限制。若登录已失效，重新进入该页面完成登录即可。需要彻底退出时，使用“清除登录状态”；该操作会删除当前用户的持久化浏览器目录，之后必须重新登录。

## 4. 创建采集任务

进入“采集任务”，可以选择内置检索流程，也可以编辑关键词。

### 参数说明

- **任务名称**：用于在列表中识别本次任务。
- **日期范围**：开始日期到结束日期，结束日期不能晚于今天，单次最多 180 天。
- **关键词**：每个任务 1–10 个关键词。每个关键词单独设置目标笔记数，默认 50，不设置产品级数值上限。
- **隐私确认**：创建前必须确认自己有权采集和处理相关图片。

系统固定选择“最新”排序，只保存图文笔记，不保存视频笔记。某个关键词结果不足时会保存实际结果并继续下一个关键词。一个笔记被多个关键词命中时，只归入首次命中的关键词；同一用户已经保存过的历史笔记不会重复保存。

检索词应尽量具体，例如“血常规报告单”“CT检查报告”“病理检查报告”。宽泛关键词噪声更高，适合补漏并建议配合 AI 或人工审核。

## 5. 查看任务进度

任务卡片会显示当前状态、关键词进度和进度消息：

| 状态 | 含义 | 建议操作 |
|---|---|---|
| 排队中 | 等待执行器领取 | 正常等待 |
| 采集中 | 正在搜索和保存图片 | 可查看实时进度，不要同时打开该用户的登录浏览器 |
| AI筛选中 | AI 队列正在处理 | 等待完成，之后仍可人工修改 |
| 需要处理 | 登录失效、验证码、访问限制或页面异常 | 进入登录页人工处理后点“恢复” |
| 已暂停 | 用户或管理员暂停 | 确认条件恢复后点“恢复” |
| 待审核 | 采集完成，可筛选和导出 | 在保留期内完成审核 |
| 已导出 | 已生成过导出包 | 可在文件过期前下载 |
| 已取消/失败 | 任务不再自动运行 | 查看提示，必要时新建任务 |

不同用户的任务可以并行；同一用户一次只运行一个采集浏览器任务。数量不设上限不等于无限结果，实际结果受关键词、日期、页面返回、历史去重和平台限制影响。

## 6. 快速审核图片

进入“图片审核”后，图片默认全部保留。页面的核心操作是快速排除错误图片：

- 单击图片卡片可在“保留/排除”之间切换，再次单击即可恢复。
- 按检索来源分组查看，避免不同业务类别混在一起。
- 按关键词、笔记、保留状态或 AI 结果筛选。
- 对当前分组全选、全部排除或反选。
- 调整缩略图大小；点击预览查看大图、来源笔记和 AI 理由。

### AI 一键筛选

AI 和人工是同级操作，不是最终裁决。点击“AI 一键筛选”后，模型认为是报告单的图片设为保留，认为不是报告单的图片设为排除。完成后应继续人工 review：

- 点击误判图片直接修改。
- 可按 AI 报告/非报告/未判断过滤。
- 可撤销最近一次 AI 筛选，恢复筛选前的选择状态。
- 可以只对某个检索词分组执行 AI 筛选。

发起 AI 筛选前，网站会要求确认图片会发送到管理员统一配置的模型服务。管理员应根据公司的数据制度选择允许处理相关内容的模型和区域，并关注共享账号的额度、账单和限流。

## 7. 导出 ZIP 与 CSV

确认保留图片无误后，点击“一键导出”。系统会再次要求确认个人信息处理责任。导出包结构类似：

```text
任务名称.zip
├─ 血常规报告单/
│  ├─ 图片文件...
├─ CT检查报告/
│  ├─ 图片文件...
├─ manifest.csv
└─ README.txt
```

文件夹分类始终来自图片首次命中的检索词，不来自 AI 判断。`manifest.csv` 包含检索词、笔记标识、标题、作者、来源地址、发布时间、图片序号和 AI 判断等元数据。

ZIP 默认只保留 2 小时，生成后请及时下载到公司的受控存储。不要把含个人信息的导出包放入公开网盘、个人聊天工具或 Git 仓库。

## 8. 数据保留规则

- 浏览器登录状态长期保存在该用户独占目录中，直到用户或管理员主动清除、账号停用或目录迁移失败。
- 候选图片进入待审核后默认保留 24 小时。
- 无论任务状态如何，候选图片最长保留 48 小时。
- 导出 ZIP 默认保留 2 小时。
- 图片文件清理后，部分任务与审计元数据仍会保留，但图片路径和部分笔记文本会被清空。

“登录状态长期保存”和“采集图片短期删除”是两套独立规则。

## 9. 管理员操作

管理员在网页中可以：

- 创建用户并获得一次性初始密码。
- 停用或启用用户。
- 重置用户密码并使旧会话失效。
- 清除某个用户的平台浏览器登录目录。
- 查看全局队列，暂停、恢复、取消或调整任务顺序。
- 手动执行过期文件清理。

停用用户前应先检查其运行中任务。清除浏览器登录是不可逆操作，不会删除该用户的任务和已采集图片，但下次采集必须重新登录。

## 10. 常见问题

### 任务一直排队

确认执行器已经启动、运行账号仍处于登录的 Windows 桌面会话，并查看管理员队列和 `logs/`。同一用户已有运行中任务时，后续任务会等待。

### 显示“需要处理”

根据提示进入登录页处理登录失效、验证码或确认页面。系统不会自动处理这些限制。完成后返回任务列表点击“恢复”。

### 登录或保存操作提示“拒绝跨站请求”

通常是反向代理没有保留正确的公开 Host，或同时通过不同域名/IP访问网站。始终使用正式 HTTPS 域名，清除该站点 Cookie 后重试；仍失败时联系 IT 检查代理的 Host/Origin 配置。

### AI 测试失败

检查 API Key、Base URL、模型名称、账户额度和服务器到模型服务的 HTTPS 网络。OpenAI-compatible 模型必须支持图片输入和 Chat Completions 格式。

### 结果少于目标数

这可能是日期范围内实际结果不足、视频被排除、历史去重、页面未返回更多内容或触发平台限制。系统会保存实际结果，不会为了凑数绕过页面限制。

### 导出无法下载

导出包可能已经超过 2 小时保留期。若候选图片仍在审核期内，可以重新生成；图片已清理时则无法恢复。
